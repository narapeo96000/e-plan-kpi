# การนำเข้าฐานข้อมูล (Production)

หมายเหตุสั้น ๆ และขั้นตอนที่ปลอดภัยสำหรับการนำเข้าไฟล์ SQL ไปยังระบบจริง

Prerequisites
- ติดตั้ง `mysql` และ `mysqldump` (MySQL client) และให้คำสั่งอยู่ใน `PATH` ของเครื่อง
- มีบัญชีผู้ใช้ฐานข้อมูลที่มีสิทธิ์สำรอง (LOCK/SELECT) และนำเข้าข้อมูล (CREATE/INSERT/ALTER)
- สำรองข้อมูลปัจจุบันก่อนการนำเข้า

ขั้นตอนแนะนำ
1. ทดสอบนำเข้าบนสภาพแวดล้อมทดสอบก่อน (staging) ให้แน่ใจว่าไม่มีข้อผิดพลาด
2. บนเครื่องที่มีการเข้าถึงฐานข้อมูล production ให้รันสคริปต์สำรองและนำเข้า:

```powershell
# รันสคริปต์จากโฟลเดอร์โปรเจค
.\n+\scripts\import_db.ps1
```

สคริปต์จะ:
- ขอข้อมูล Host, User, Password, Database และตำแหน่งไฟล์ SQL
- สร้างไฟล์สำรองด้วย `mysqldump` ชื่อ `<dbname>-backup-<timestamp>.sql`
- นำเข้าไฟล์ SQL ที่ระบุเข้าไปในฐานข้อมูล

ข้อควรระวัง
- อย่าเรียกสคริปต์นี้ถ้าคุณไม่มีการเชื่อมต่อที่ปลอดภัยกับ DB (ใช้ VPN/Private network)
- ถ้าไฟล์ SQL ใหญ่ ควรรันในโหมดที่รองรับการคืนค่าหรือแบ่งไฟล์
- ตรวจสอบ `migration_upgrade.sql` ถ้ามีขั้นตอนอัพเกรดที่จะต้องรันเพิ่มหลังนำเข้า

หากต้องการ ผมสามารถ:
- ปรับสคริปต์ให้ทำงานแบบ non-interactive (รับพารามิเตอร์จากบรรทัดคำสั่ง)
- สร้างเวอร์ชันสำหรับ Linux (bash)
- ช่วยรันคำสั่งนำเข้าในเซิร์ฟเวอร์ที่คุณให้สิทธิ์การเข้าถึง
