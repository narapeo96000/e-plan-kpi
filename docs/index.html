e-PLAN

ระบบติดตามและรายงานผลการขับเคลื่อนตามแผนพัฒนาการศึกษาจังหวัดนราธิวาส
(Budget • Project • OKR Monitoring with KPI)

e-plan-kpi · Narathiwat Education

เกี่ยวกับระบบ

ระบบสำหรับหน่วยงานทางการศึกษาจังหวัดนราธิวาส ใช้ติดตามโครงการ งบประมาณ และผลการดำเนินงาน ตามยุทธศาสตร์พร้อมการกำหนดตัวชี้วัด KPI ร่วมระดับจังหวัด/หน่วยงาน และการรายงานความก้าวหน้าแบบ OKR

คุณสมบัติหลัก

📋

จัดการโครงการ

เพิ่ม แก้ไข รายงานผลโครงการ พร้อมแนบเอกสาร รูปภาพ และวิดีโอ ตามยุทธศาสตร์

💰

ติดตามงบประมาณ

งบจัดสรร งบใช้จ่าย สัดส่วนการใช้จ่าย และการเบิกจ่ายแบบรายการ

📐

ตัวชี้วัด KPI

กำหนด KPI ร่วมสำหรับจังหวัด/หน่วยงาน พร้อมค่าเป้าหมายร้อยละและตัวชี้วัดความสำเร็จ

🎯

OKR

ติดตามความก้าวหน้าของหน่วยงานผ่าน Objectives & Key Results

📊

Dashboard

ภาพรวมสัดส่วนการดำเนินโครงการ กราฟตามยุทธศาสตร์ และรายงานส่งออก PDF/Excel

🔐

หลายระดับสิทธิ์

Admin, ผู้กำหนด KPI, ผู้ประสานงานหน่วยงาน และผู้ใช้ทั่วไป พร้อมประวัติการแก้ไข

บทบาทผู้ใช้

  • ผู้ดูแลระบบ (admin) — เข้าถึงทุกอย่าง จัดการผู้ใช้และข้อมูลทั้งหมด
  • ผู้กำหนดตัวชี้วัด KPI (plan) — กำหนดตัวชี้วัดร่วมสำหรับจังหวัด/หน่วยงาน
  • ผู้ประสานงานหน่วยงาน (office) — จัดการโครงการของหน่วยงานตนเอง และแก้ไขแทนเจ้าของ
  • ผู้ใช้ทั่วไป (user) — เพิ่ม/แก้ไข/รายงานเฉพาะโครงการของตนเอง
